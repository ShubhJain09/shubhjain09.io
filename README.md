# SHUBH — Portfolio

A premium dark/editorial portfolio starter built with plain HTML, CSS and JavaScript.

## Run locally
1. Open `index.html` in a browser, or use VS Code Live Server.
2. Replace `YOUR_EMAIL@example.com` in `index.html` with your real professional email.
3. Replace the three concept projects with your actual projects as you build them.
4. Deploy with GitHub Pages when ready.

## Important
The project names and descriptions are intentionally presented as concepts/experiments. Do not claim they are client projects unless they actually are.
